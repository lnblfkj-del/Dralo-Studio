# Selected Timeline Core

`timeline.ts` adapts `getVisualSegmentTimeline` and `reorderTimelineItems` from
MartinDelophy/ai-video-editor, commit `d5e9b3f576957289d068f715c8149e70d7cf42ba`,
`src/lib/timeline.js`. Units are integer frames; media access and persistence are
implemented by this application, not the upstream application state.
