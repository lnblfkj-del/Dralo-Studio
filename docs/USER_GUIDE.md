# 使用指南

## 第一次使用

1. 按安装指南启动 API 与 Worker，使用自己的本机管理员账号登录。
2. 在模型管理中添加渠道与模型。模型凭据不由本项目提供，首次安装默认没有已配置模型。
3. 先做一个小项目，测试一次文本生成，再尝试图像、视频与语音。先确认费用与输出格式，避免批量任务误触发大额调用。

## 从故事到作品

上传 TXT、Markdown 或 DOCX 剧本，也可以粘贴文本、从灵感开始创作。逐步整理故事与分集内容，管理人物、场景和资产，再组织镜头。风格库帮助选择提示词方向，实际生成结果仍由模型和参数决定。

自由画布用于连接素材和创作节点；多轨编辑用于整理镜头、声音与字幕。3D 导演台用于人物摆位、机位预演与画面参考，不是通用 3D 建模软件。

任务中心用于检查状态、错误及结果。调用失败时先检查渠道地址、模型标识、凭据、服务商限制和参考素材可访问性。

## 文件、缓存与备份

单机版的项目元数据默认位于 `data/`，素材位于 `storage/`，日志位于 `logs/`，具体可由 `.env` 和存储配置调整。停掉 API 与 Worker 后再备份 SQLite 文件。

备份至少包含数据库、项目素材、存储配置和 `.env`。模型加密密钥不能仅靠重新生成恢复。日志也可能含项目描述或模型错误，请先脱敏再分享。

官网提供的云端客户端有自己的下载与本机缓存功能，不能与本仓库单机源码的存储路径混为一谈。

## 对象存储

对象存储由使用者自行开通和配置，本项目不提供额度或代付。官方 MiniMax H3 等需要公网参考链接的模型，应先配置对象存储及相应访问权限。不要默认把所有素材桶设为公开；采用供应商支持的签名 URL 或最小化权限配置。

对象存储、模型调用、语音服务和公网流量都可能产生费用。删除本地文件也不一定会自动删除服务商保存的远端副本。

## 发布作品前

确认剧本、人物肖像、声音、图片、音乐和 3D 模型的使用权；核对模型供应商对输出内容的规定。开源软件许可证不替你取得素材授权。

市场探索及外部搜索需要相应服务可用；可选 ASR/渲染运行时没有随源码附带权重。若某项功能尚未完成环境配置，请不要把错误归因于缺失的官方模型账号。
