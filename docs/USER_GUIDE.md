# 使用指南

## 第一次使用

1. 按安装指南启动 API 与 Worker，使用自己的本机管理员账号登录。
2. 在模型管理中添加渠道与模型。模型凭据不由本项目提供，首次安装默认没有已配置模型。
3. 先做一个小项目，测试一次文本生成，再尝试图像、视频与语音。先确认费用与输出格式，避免批量任务误触发大额调用。

## 从故事到作品

上传 TXT、Markdown 或 DOCX 剧本，也可以粘贴文本、从灵感开始创作。逐步整理故事与分集内容，管理人物、场景和资产，再组织镜头。风格库帮助选择提示词方向，实际生成结果仍由模型和参数决定。

自由画布用于连接素材和创作节点；多轨编辑用于整理镜头、声音与字幕。3D 导演台用于人物摆位、机位预演与画面参考，不是通用 3D 建模软件。

任务中心用于检查状态、错误及结果。调用失败时先检查渠道地址、模型标识、凭据、服务商限制和参考素材可访问性。

## 资产图片与提示词

拆解得到的基础提示词可直接生成图片；需要更具体的画面描述时再优化。卡片显示提示词状态，关闭优化弹窗后任务继续运行。默认批量优化跳过已优化与正在优化的资产，重新优化须明确选择。修改资产资料后旧优化标记失效，但原提示词不会被静默删除。

生成成功的最新图片按用途自动采用；历史版本仍可手动选择。侧面、背面与主图独立保存，已冻结的视频任务不会因图片更新改变输入。失败、无效文件或旧任务迟到不覆盖已采用主图。

服装本体模式不绑定人物，提示模型只表现衣物；角色穿着模式需要有效角色参考。三视图和四视图会分别提交图片任务，每个视图都可能计费，文字约束不能保证每个图片模型百分之百遵循构图。

## 失败恢复

“响应已保存，处理失败”不等于模型请求失败。先在任务中心查看字段诊断并尝试本地重新处理；成功子任务保留。缺失关键结构或有歧义的来源不能靠虚构数据补齐，必要时仅对失败范围重新调用。

“渠道暂无可用图片资源或额度”会暂停后续提交，不代表已经确认你的账户余额不足。核对服务商资源、配额或账单后继续未提交项，失败项单独确认重试。请求结果不确定时不要反复点击生成。

## 文件、缓存与备份

更新已有部署时，先等待任务完成并停止 API 与 Worker，备份数据库、素材、`.env` 和存储配置，再更新源码、重建前端并重启。本轮资产修复没有新增数据库迁移，不要删除数据库或重建加密密钥。

内置创作 Skill 可在停机备份后单独升级。在 `apps/server` 先运行下列预检；默认回滚，不持久修改。通过后在末尾加 `--apply` 正式应用。自定义规则拒绝覆盖，失败则整轮回滚。升级保留历史版本和任务快照，不重发模型请求，不改变风格库或模型配置。

```bash
python -m app.services.catalog_upgrade --skills outline.direction outline.story_bible outline.rewrite script.from_brief script.rewrite episode.script-analysis.v1 episode.shot-planning.v1 episode.segment-grouping.v1 episode.asset-binding.v1 episode.prompt-compiler.v1 episode.continuity-check.v1
```

单机版的项目元数据默认位于 `data/`，素材位于 `storage/`，日志位于 `logs/`，具体可由 `.env` 和存储配置调整。停掉 API 与 Worker 后再备份 SQLite 文件。

备份至少包含数据库、项目素材、存储配置和 `.env`。模型加密密钥不能仅靠重新生成恢复。日志也可能含项目描述或模型错误，请先脱敏再分享。

官网提供的云端客户端有自己的下载与本机缓存功能，不能与本仓库单机源码的存储路径混为一谈。

## 对象存储

对象存储由使用者自行开通和配置，本项目不提供额度或代付。官方 MiniMax H3 等需要公网参考链接的模型，应先配置对象存储及相应访问权限。不要默认把所有素材桶设为公开；采用供应商支持的签名 URL 或最小化权限配置。

对象存储、模型调用、语音服务和公网流量都可能产生费用。删除本地文件也不一定会自动删除服务商保存的远端副本。

## 发布作品前

确认剧本、人物肖像、声音、图片、音乐和 3D 模型的使用权；核对模型供应商对输出内容的规定。开源软件许可证不替你取得素材授权。

市场探索及外部搜索需要相应服务可用；可选 ASR/渲染运行时没有随源码附带权重。若某项功能尚未完成环境配置，请不要把错误归因于缺失的官方模型账号。
