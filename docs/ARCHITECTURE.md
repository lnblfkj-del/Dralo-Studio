# 功能与系统架构

## 一套本地创作工作流

工作台围绕项目组织内容：故事设定与剧本、角色与场景、分集与镜头、项目素材、多轨编辑。自由画布提供另一种组织与连接素材、生成节点的方式。任务中心承载耗时操作的进度与结果。

用户自行设置模型渠道、模型参数和智能体/Skill 配置。模型的实际能力、格式约束、价格及可用性由相应服务商决定。

## 运行边界

```text
本机浏览器
    |
    v
React 工作台 ------ 3D 导演台
    |
    v
FastAPI 本地 API ---- SQLite 项目元数据
    |                      |
    +---- 素材文件 / 本地存储
    |
    v
独立 Worker ---- FFmpeg / 可选媒体运行时
    |
    +---- 用户配置的模型服务与对象存储
```

默认前端静态文件由 API 提供。开发模式可以单独运行 Vite。

API 与 Worker 共享本机配置、数据库与素材路径。Worker 负责异步生成和处理，不需要把官方云端服务部署到自己的电脑。

## 主要模块

| 目录 | 职责 |
| --- | --- |
| `apps/web/src/pages` | 工作台、项目、画布、素材与设置等页面 |
| `apps/web/src/components` | 编辑器、风格库、多轨及可复用 UI |
| `apps/server/app/api` | 本地 HTTP 接口 |
| `apps/server/app/services` | 创作、资产、模型、存储与媒体业务 |
| `apps/server/app/jobs` | 后台任务与 Worker |
| `apps/server/app/models` | 数据库模型 |
| `apps/server/migrations` | 独立单机 SQLite 迁移基线 |
| `apps/director-upstream` | 3D 分镜导演台及其第三方许可 |
| `packages/types` | TypeScript 共享类型 |

## 与官方云端的区别

这里不公开云端内测账号运营、公告反馈后台、服务器部署脚本、云端多租户管理与轻量客户端发布代码。单机版不是连接官方云端的 Electron 客户端。

单机初始化会拒绝 `cloud` 执行模式。部分共享模块仍有运行位置判断，用于维持通用业务契约，不代表公开了官方云端部署实现。

## 资源约束

内置风格用于创作提示与视觉示例；第三方模型及动作资源有各自授权要求。公开源码不随附尚未确认可再分发的资源包。3D 导演台采用程序化默认人物，支持使用者自行导入合法持有的模型。

语音识别、某些编辑渲染能力可能需要额外的模型/运行时。它们不是 Python 和 JavaScript 依赖安装完成后就自动具备的模型权重。
