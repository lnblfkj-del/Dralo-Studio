# R3 片段规划与音频模型配置

R3 使用内容驱动的规划流程，不沿用旧边界规划器或旧任务。旧部署必须先按 [切换说明](UPGRADING.md) 归档并准备独立新库；前端、API 和 Worker 使用同一源码版本。

## 规划流程

1. 确认分集正文。原创和完整上传正文使用同一条链路；不完整材料先完成正文，不猜测说话人或省略原文。
2. 选择文本规划模型、视频模型及已核验模式。提交前检查当前路由、时长、画幅、分辨率、镜头数、参考素材及声音能力。
3. 文本模型分析动作、对白、旁白与声音的时间需求；本地求解器按模型规格组合片段。每集约 45 秒是创作目标，不是要求强行凑满的硬时长。
4. 冻结片段数量、时长和来源，再生成详细脚本。详细脚本只能填充冻结计划，不能自行增加片段、删除正文或改变时长。
5. 完整保存后启用制作台。规划和启用不会自动生成视频；视频任务单独预检并确认费用。

上传场次标题支持 `1-1 修表铺 日 内` 和 `1-1 修表铺 内 日` 等已测格式；不能据此推定任意 DOCX 排版都能正确解析。不明确的来源保留并提示核对。

## 文本模型

选择当前渠道实际支持的文本协议和结构化输出模式，并明确配置输出预算、总超时、首响应与流式空闲超时。预算不足或渠道不支持原生结构化格式会失败，不能只做连接测试就视为完整验收。

2026-10-11 的 R3 云端验收使用实际配置的 `gemini-3.1-pro-high` 路由：原创和上传格式各完成一次分析及一次详细脚本生成，完整保存并启用制作台，短样本分别约 62 秒和 51 秒。这是有限样本，不是整集生成时延承诺或全球模型稳定性排名。

此前 `gpt-6-sol` 严格结构化模式有独立有限验收记录，可作为配置起点；同名代理不等于同一能力。DeepSeek 及其他路由仍须以本部署的真实输出复验。不要照抄作者的私有渠道地址、模型编号或手工“已验证”标记。

## 视频规格与换模

规划只使用当前路由已核验的模式。能力改变、换协议或换接口地址后需要重新核验；模型名称不能代替规格契约。

MEAICC 视频使用专用 `meaicc_video` 协议，不套用平台列表展示的 OpenAI 文本接口。[平台文档](https://api.meaicc.com/create/sd-2.html) 声明时长 5–15 秒；当前渠道还实际返回过 4 秒边界样本。规划登记保守的整数秒范围，不能把只实测过的几个时长误写成模型只支持这几个离散值，否则自然约 6 秒的对白也会被误判不兼容。

本轮有限样本覆盖文生、720p、16:9，以及边界和中间时长。15 秒样本出现五个顺序镜头，但切点并非严格每三秒。文档范围与抽样核验不等于每个时长均已逐一实测，更不代表多参考图、首尾帧或跨片段布景一致性通过。单张参考图的独立样本成功不等于该输入模式已开放于规划。

换视频模型先检查当前片段的时长、镜头数、参考数量和音频能力。全部符合才复用；例如 15 秒片段不能直接交给只支持 8 秒的模型，必须重新规划受影响内容，不重新创作整集正文。换模和重新预检本身不产生视频生成费用。

无法满足规格时明确报告受阻内容，不靠无限补时、截断对白或静默删除参考素材过关。

## 配音与配乐

- 视频原生对白、环境声和独立声音资产分别处理。未生成 TTS/BGM 资产时，只有经过核验的视频原生声音模式才可直接输出相应声音。
- 配乐开关位于片段规划设置，默认关闭。提示词偏好控制不是服务商的硬静音参数，需要试听。
- StepFun 配音使用 `stepfun_tts`，音乐使用 `stepfun_music`；先核验当前账户、模型和可用音色。音乐仅支持纯器乐，不能指定精确时长。配音中的演绎说明与实际朗读文本分开，不静默丢弃括号台词。
- MiniMax Audio API Subscription 的已适配范围是 TTS，不把订阅理解为音乐权限。ElevenLabs TTS 与 Music 分别配置协议、账户权限及输出参数。这两家的真实账户尚未验收，不标记为已通过。
- 需要可运行的 FFmpeg/FFprobe 进行媒体检查。音频资产生成后保留为候选，不自动代替已经采用的声音素材。

## 失败、恢复与费用

当前页面先检查能否恢复已保存响应；保存失败优先重试保存，不再次调用模型。确需新调用时明确列出未完成范围和可能再次收费，用户确认后才执行。已经成功的片段保留，不为一个失败片段重新生成整集。

来源或模型能力已经变化时，旧响应不能强行绑定新计划。结构截断、缺失正文、身份不明和规格冲突都不能通过补空值或删除内容伪装成功。

重复点击同一请求不会创建第二个任务；不同收费请求仍可能再次计费。超时且上游结果未定时先查询渠道任务编号，不能把本机停止当成上游取消。没有价格或结算数据时金额未知，不能显示成免费。

自动测试和有限真实样本不保证模型永远不出错。遇到问题保留任务编号与脱敏详情，暂停新生成；不要公开 `.env`、密钥、客户原文或完整模型响应。
