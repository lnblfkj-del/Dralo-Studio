# 近 10 天更新汇总

统计时间：2026-10-10 至 2026-10-19（含首尾两日）。
适用范围：Dralo Studio 单机开源源码，以当前 main 为准；不是云端客户端安装包更新通知。

本次按公开提交、现有发布说明和已完成的运行验证整理，不将讨论过但未落地的方案列为已完成。

## 更新概览

这轮主要围绕“剧本创作 → 资产拆解 → 声音与视频制作”梳理工作流，重点减少重复配置、保留成功结果，并改善失败后的恢复操作。

| 模块 | 主要变化 |
| --- | --- |
| 模型管理 | 精简配置、统一弹窗、费用与高级设置折叠、独立生成测试 |
| 音频制作 | 区分角色参考声线、指定音色配音、配乐、歌曲和环境音效 |
| 资产拆解 | 强化来源证据、身份与别名整理、人工决定和批量恢复 |
| 剧本与视频 | 内容驱动规划、来源版本保护、视频规格与参考素材校验 |
| 界面与发布 | 修复阶段状态与刷新定位，补充开发商、版本和升级说明 |

## 一、模型管理与界面

- 调整模型编辑布局，紧凑排列输入框、下拉框及能力配置，统一主要保存操作的紫色样式。
- 内容型弹窗统一采用 1200 × 860 的目标规格，小屏按可用空间收缩；放弃修改、删除等确认弹窗保持紧凑，不再套用大型内容弹窗尺寸。
- 费用设置、高级设置支持折叠，减少默认展开的信息量。
- 默认使用渠道连接配置，模型级连接与超时例外集中管理，减少重复填写。
- 改善添加模型后的列表展示，避免搜索状态让其他已添加模型看起来“消失”。
- 精简渠道操作文案，将“发现模型（不生成）”改为“发现模型”。
- 增加模型页独立生成测试入口；实际可用测试类型受模型协议、能力及渠道配置限制。
- 工作台首页及登录页显示开发商“广东麦佳信息技术有限责任公司”和软件版本。

## 二、TTS、参考声线与音乐

- 明确区分用途：角色声音以短参考声线为主，不把角色的全部台词默认提交为一条参考音频；配乐及环境音效用于后续多轨制作。
- 扩展 StepFun 与 ElevenLabs 的独立音频流程，按渠道协议配置，不再将不同厂商视为同一种请求。
- 支持 StepFun 声线生成流程，以及 ElevenLabs 参考声线设计、指定音色配音流程；不是所有 TTS 模型都支持只用声线描述生成。
- 音色目录、默认音色及音色 ID 用于需要指定发音人的配音模式，不作为所有参考声线生成的统一前置要求。
- 音乐配置区分纯器乐与歌曲，相关入口按渠道支持情况展示；不能以“纯器乐能力”代表所有音乐生成能力。
- 资产音频与 BGM 流程联动，补充批量生成操作；视频模型的原生对白能力与独立声音资产分开处理。
- 改善音色目录的表格布局及长文本显示。渠道未提供试听样本、类型或语言元数据时，不承诺可直接试听或补出未知信息。
- 测试结果可清理，并处理关联测试素材；不能只让记录消失而将可清理的测试资产遗留在资产库。正式采用或被引用的素材仍需遵守引用保护。
- 检查连接、读取目录不等于真实生成成功；真实生成仍需确认可能产生的费用。

## 三、资产拆解、核对与入库

- 拆解结果保留原文出处及版本信息，分别整理角色身份、别名、外观形态、服装与其他必要资产。
- 改善别名与正式名称冲突的处理，不再仅凭同名或相似称呼将不同角色强行合并。
- 可确认的候选与待决定项目分开处理，正常候选可先入库，不因少数不确定项要求重跑全部内容。
- 待核对项支持查看证据、修订字段、独立保留、选择合并目标、排除及恢复；来源或身份没有充分证据时仍需人工决定。
- 对角色形态、视觉关联和声音关系分别处理，保留人工决定及审计信息，不以关闭检查替代解决冲突。
- 改善分批结果保存与恢复，保留已经成功的范围；失败范围可以单独处理。
- 新增失败范围勾选及批量恢复，区分“重新处理已保存结果”与“重新调用模型生成”，减少逐条点击。
- 批量恢复先确认范围及费用风险，展示逐项处理结果；单项失败不要求放弃其他成功结果。
- 调整恢复列表：移除全选框，每集选择框放在最前面，“第 N 集 · 必要资产”单行显示，操作按钮保持规整。

## 四、剧本正文、阶段状态与视频规划

- 正文识别覆盖明确场次、动作、旁白、设备语音、多人合说及折行台词；不明确的发声来源保留原文并提示核对。
- 创作、正文确认与制作使用一致的来源及版本约束，避免将格式差异直接当作内容缺失。
- 片段规划按正文动作、对白及当前视频模型规格求解数量和时长，不把约 45 秒目标硬套成固定成片时长。
- 分离分析、冻结计划与详细脚本填充；模型切换不兼容时需要重新规划，不静默删台词或减少参考素材。
- 更新 MEAICC 等视频协议、参考媒体及执行配置；具体参考素材数量以模型与渠道能力为准。
- 配乐开关集中在片段规划设置，默认关闭；关闭非剧情配乐不代表关闭对白、环境声或剧情内音乐。
- 优先恢复有效的已保存响应，避免把本地处理失败直接变成新的收费调用。
- 修复资产关联核对问题误将已确认正文显示为未完成的问题。
- 修复分批资产入库完成后制作准备状态未更新，以及制作准备页刷新回跳到剧本正文的问题。

## 五、开源发布与运行验证

- 发布单机源码 v0.1.0-preview.3，随后在 main 补充开发商与版本页脚。
- 公开源码不包含作者账号、渠道密钥、本机项目数据库、生成素材或模型额度。
- 已完成源码构建、隔离空库初始化、登录、内置风格与图片检查，以及已发布 R3 数据库的增量升级和重复初始化验证。
- 从 GitHub 版本独立克隆，使用隔离 Python 环境及独立数据库启动 API、Worker 与前端，完成登录、项目创建、正文保存确认、资产创建和主要页面检查。
- 上述独立运行检查未调用收费模型，不能等同于所有渠道的真实生成验收。
- 页脚改动已通过构建与浏览器显示检查。

## 六、升级与已知边界

1. 更新前备份数据库、素材和现有配置，保留原渠道加密密钥。
2. 当前 SQLite 迁移为 ds_r3_0002；已发布 ds_r3_0001 保持原样，通过新增迁移升级。更早或内部测试库请按升级文档处理，不要直接删库。
3. 同步更新前端、API 和 Worker，按部署说明重建及重启；不要只替换其中一部分。
4. 上游 401、502、503、额度不足、响应截断及生成质量仍受服务商影响，本轮不承诺任何渠道永不失败。
5. 价格未知不是免费；重新调用模型可能再次收费。已保存响应的本地恢复与新的生成必须区分。
6. Windows 隔离验证不代表所有操作系统、模型组合及声线质量均已验收；可选 ASR 权重、大型模块构建体积等限制仍在。
